# Beyond Compulsory Scarcity — AARC

A responsive research concept site about autonomous plant-based food production, provisional 30-crop planning, food access and shared abundance.

## Run locally

```sh
npm install
npm run dev
```

Build the production bundle:

```sh
npm run build
```

Preview the production bundle:

```sh
npm run preview
```

The site is a Vite + React + TypeScript application. It uses Motion for interface animation and Lucide React for icons. Npm cache and log directories are kept in `.npm-cache/` and `.npm-logs/` within this project.

## Site map and interactions

The home page presents the provisional 30-crop portfolio, acreage model, plant-based 21-meal plan and periphery-to-periphery operating concept. Each crop card opens an individual research profile at `#/crop/<crop-name>` with current commercial capabilities, crop-specific automation gaps, a workflow, a proposed next experiment and source links. Additional sections cover the philosophical thesis, engineering, food access, participation and the searchable asset library at `#/assets`.

The site includes animated field and crop details, silent short video loops, GIF excerpts and a filterable library of 74 locally stored media assets. `ASSET-CREDITS.md` lists image creators, source pages and reuse terms. Four original 4K Pexels source videos are retained in `assets/4k-video-sources/`; the site uses smaller web derivatives. Motion effects respect reduced-motion preferences.

## Content status

Central Iowa is a provisional reference location. The 100-acre allocation, 30-crop portfolio, equipment shortlist and autonomy architecture are design hypotheses for discussion—not validated agronomic, nutrition, financial, safety or procurement guidance. Supplier references are candidates for due diligence, not endorsements. The interest form is a non-transmitting demo; configure a real privacy-aware form service before launch.

The 21-meal menu is plant-based and illustrative. Portion sizes, nutrient adequacy, allergens, food safety and culturally appropriate substitutions require qualified review and recipient input.
